# 이슈 분류 라벨

스킬에서 아래 분류 역할을 지정하면 대응하는 GitHub 라벨을 사용한다.

| 분류 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 검토가 필요한 이슈 |
| `needs-info` | `needs-info` | 추가 정보가 필요한 이슈 |
| `ready-for-agent` | `ready-for-agent` | 에이전트가 구현할 수 있도록 요건이 정리된 이슈 |
| `ready-for-human` | `ready-for-human` | 개발자가 직접 구현해야 하는 이슈 |
| `wontfix` | `wontfix` | 처리하지 않기로 결정한 이슈 |
