# GitHub Issues

이슈 트래커는 `ideale17/spring-quartz-scheduler`의 GitHub Issues다.
연결된 GitHub 플러그인을 우선 사용하고, 해당 기능이 없으면 사용 가능한 GitHub 연동 도구를 확인한다.
GitHub CLI(`gh`)는 선택 사항이다. 필요한 도구가 없으면 사용자에게 알리고 설치 전 승인을 받는다.

이슈 게시가 필요한 경우 초안을 먼저 보여준다. 이슈 생성·수정·종료,
댓글 게시, 이슈 라벨 변경, 저장소 라벨 등록은 대상과 변경 내용을 설명하고
사용자의 명시적 승인을 받은 뒤 수행한다.

상위·하위 관계는 GitHub 하위 이슈로, 선행 작업은 이슈 의존성으로 기록한다.
코드리뷰는 사용자가 지정한 PR에서 진행한다.

**PRs as a request surface: no.**
